Privacy Policy — Canal GTA Uploader

Last updated: November 18, 2026

Canal GTA Uploader ("the Tool") is a private, single-user software tool operated by the owner of the channel PORTAL GTA VI / HIGHLIGHTSGTA6 (YouTube channel ID UCQOv5CtyQZcf2pc63WNGdXQ; TikTok account @highlightsgtavi). It runs only on the owner's personal computer and is not offered to the public.

1. What the Tool does

The Tool uses YouTube API Services and TikTok developer APIs to: (a) upload and schedule videos to the owner's own YouTube channel and TikTok account, after the owner approves each video; (b) read the owner's own account information and video statistics (including YouTube Analytics) to produce a private performance report for the owner.

By using the Tool, the owner agrees to be bound by the YouTube Terms of Service and the TikTok Terms of Service. The Tool uses YouTube API Services; see the Google Privacy Policy.

2. Information accessed

Through OAuth 2.0 (Google and TikTok), with the owner's explicit consent, the Tool accesses only the owner's own account data: account/channel ID, name and public statistics; the owner's videos, their metadata and statistics; YouTube Analytics metrics for the owner's channel. The Tool does not access data from any other user and does not collect personal information from viewers.

3. How information is used

Data is used solely to (a) upload and schedule the owner's videos after the owner approves them, and (b) generate a private daily report for the owner. It is not used for advertising, profiling or any other purpose.

4. Storage and security

OAuth credentials and tokens are stored only on the owner's local computer, in a folder not synchronized to any cloud service. Reports are stored as local notes on the same computer. No data is stored on any server operated by the Tool; the Tool has no server.

5. Sharing

YouTube and TikTok data is not sold, rented, shared with, or disclosed to any third party.

6. Data retention and deletion

Local data is kept only as long as needed for the reports and can be deleted at any time by deleting the local files. Access can be revoked at any time at Google security settings and in the TikTok app (Settings → Security and permissions → Apps and services), after which the Tool can no longer access the accounts.
